# Architecture Decision Records

One file per structural decision: `NNNN-short-title.md`, numbered in order.

Each ADR is short — **context** (what forced the decision), **decision**
(what we chose), **consequences** (what it costs us later). A commit
message or a chat thread is not a durable record.

The rest of `docs/` (cheatsheets, recaps) is personal scratch and stays
git-ignored; this directory is the exception.
